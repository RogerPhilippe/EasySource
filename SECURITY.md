# Security policy

[English](#english) · [Português (BR)](#português-br) · [Español](#español)

## English

### Supported versions

Only the [latest release](https://github.com/RogerPhilippe/EasySource/releases/latest)
receives security fixes. Please update before reporting.

### Reporting a vulnerability

**Do not open a public issue for security problems.** Report them privately:

1. Preferred: on GitHub, open the **Security** tab of this repository and click
   **Report a vulnerability**.
2. Or by email: rogerphilippepereira@gmail.com, with "EasySource security" in the subject.

Please include the EasySource version, your operating system, the steps to
reproduce and, if possible, a proof of concept. You will get an acknowledgement
within 7 days. Once a fix is released, you will be credited in the release notes
unless you prefer to remain anonymous.

### Scope

In scope: the EasySource app and its packages published on the Releases page.
Out of scope: vulnerabilities in Git itself, in Electron/Chromium that are already
fixed upstream and pending an update here, and attacks that require an attacker
who already controls the user's account or machine.

## Português (BR)

Só a [versão mais recente](https://github.com/RogerPhilippe/EasySource/releases/latest)
recebe correções de segurança.

**Não abra uma issue pública para problemas de segurança.** Reporte de forma privada
pela aba **Security → Report a vulnerability** deste repositório, ou pelo e-mail
rogerphilippepereira@gmail.com com "EasySource security" no assunto. Informe a versão,
o sistema operacional e os passos para reproduzir. Você recebe uma resposta em até 7 dias.
