# Contribuindo com o EasySource

Obrigado pelo interesse em contribuir! Leia o que segue antes de abrir um Pull Request.

## Como contribuir

1. Abra uma Issue descrevendo o bug ou a funcionalidade proposta, para alinhar antes de programar (evita retrabalho).
2. Faça um fork do repositório e crie uma branch a partir da `main`.
3. Siga o estilo de código já usado no projeto.
4. Rode `npm test` e `npm run test:smoke`, e teste suas alterações no app (`npm start`) antes de abrir o PR.
5. Descreva claramente, na descrição do PR, o que foi alterado e por quê.

## Somente trabalho original

- Não envie código, ícones, imagens, textos ou outros recursos copiados,
  descompilados ou adaptados de produtos de terceiros, a menos que a licença
  deles permita e seja compatível com este projeto.
- Não envie código copiado ou adaptado de projetos cuja licença seja
  incompatível com o modelo de licença dupla deste projeto (por exemplo,
  código apenas GPL).

As contribuições devem ser trabalho original seu, ou vir de fontes sob
licenças permissivas (MIT, BSD, Apache-2.0, ISC), com seus avisos preservados.

publicamente sob a [AGPLv3](LICENSE) e também é oferecido sob uma
