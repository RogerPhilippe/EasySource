# Contributing to EasySource

Thanks for your interest in contributing! Please read the following before opening a Pull Request.

## How to contribute

1. Open an Issue describing the bug or proposed feature, to align before coding (avoids rework).
2. Fork the repository and create a branch from `main`.
3. Follow the code style already used in the project.
4. Run `npm test` and `npm run test:smoke`, and try your changes in the app (`npm start`) before opening the PR.
5. Clearly describe, in the PR description, what was changed and why.

## Original work only

- Do not submit code, icons, images, texts or other assets copied, decompiled
  or adapted from third-party products, unless their license allows it and is
  compatible with this project.
- Do not submit code copied or adapted from any project whose license is
  incompatible with this project's dual-license model (for example,
  GPL-only code).

Contributions must be your own original work, or come from sources under
permissive licenses (MIT, BSD, Apache-2.0, ISC) with their notices preserved.
