# Contribuir a EasySource

¡Gracias por tu interés en contribuir! Lee lo siguiente antes de abrir un Pull Request.

## Cómo contribuir

1. Abre un Issue describiendo el error o la funcionalidad propuesta, para alinear antes de programar (evita retrabajo).
2. Haz un fork del repositorio y crea una rama a partir de `main`.
3. Sigue el estilo de código que ya se usa en el proyecto.
4. Ejecuta `npm test` y `npm run test:smoke`, y prueba tus cambios en la app (`npm start`) antes de abrir el PR.
5. Describe claramente, en la descripción del PR, qué se cambió y por qué.

## Solo trabajo original

- No envíes código, íconos, imágenes, textos u otros recursos copiados,
  descompilados o adaptados de productos de terceros, a menos que su licencia
  lo permita y sea compatible con este proyecto.
- No envíes código copiado o adaptado de proyectos cuya licencia sea
  incompatible con el modelo de licencia dual de este proyecto (por ejemplo,
  código solo GPL).

Las contribuciones deben ser trabajo original tuyo, o provenir de fuentes
bajo licencias permisivas (MIT, BSD, Apache-2.0, ISC), con sus avisos
preservados.

## Licenciamiento de las contribuciones y Acuerdo de Contribuidor

Este proyecto usa un modelo de **licencia dual**: está disponible
públicamente bajo la [AGPLv3](LICENSE) y también se ofrece bajo una
[licencia comercial separada](COMMERCIAL-LICENSE.es.md) para quienes no
pueden cumplir los términos de la AGPLv3.

Para que este modelo funcione legalmente, el mantenedor del proyecto (Roger
Philippe Pereira) necesita tener los derechos necesarios para relicenciar
comercialmente el código completo, incluidas las contribuciones de terceros.

**Al enviar una contribución (Pull Request, parche o cualquier otro
material) a este proyecto, aceptas que:**

1. Tu contribución se licencia bajo la AGPLv3, como el resto del proyecto; y
2. Otorgas al mantenedor del proyecto (Roger Philippe Pereira) una licencia

3. Declaras que tienes derecho a realizar esta contribución y esta

Si no estás de acuerdo con estos términos, lamentablemente no podremos
aceptar tu contribución a este proyecto.
